ESC: Enhanced-Keyed Shiftmerge Cipher

overview

ESC (Enhanced-Keyed Shiftmerge Cipher) is a cryptographic project developed as an enhancement of the original Shiftmerge concept. The project explores how classical substitution and transposition techniques can be combined with modern cryptographic mechanisms to create a more structured and key-dependent encryption process.

my contribution

Contributed to the development, testing, and documentation of the encryption algorithm as part of a collaborative research project.

key concepts
  • PBKDF2-HMAC-SHA256 key derivation
  • 128-bit symmetric key
  • Keyed substitution
  • Enhanced Shiftmerge transposition
  • Metadata encryption
  • ciphertext noise injection
project outcome

The algorithm was evaluated through entropy analysis and brute-force resistance testing to examine the randomness and security characteristics of its encryption stages.

note ESC was developed as an academic and research project to explore cryptographic concepts and is not intended to replace standardized cryptographic algorithms.
